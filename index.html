  • Tối ưu hiệu năng bằng indexing database, cache Redis TTL ngắn cho hot reads, batching ở resolver để tránh N+1, và xử lý batch/queue; migrate API nội bộ từ REST sang gRPC — duy trì độ trễ truy vấn đơn hàng p95/p99 ~50ms ở mức thông lượng đỉnh khoảng ~6 req/s.
  • Tech: Node.js, Express, GraphQL, gRPC, TronWeb, MongoDB, Redis.
